This project explores the anonymized AAA Social Sciences module from the Open University Learning Analytics Dataset, across the 2013J and 2014J presentations.

03

The graph contains historical facts, not explanations of personal circumstances. It does not include instructor names, study hours or the project's experimental predictions.
